# Core 1.1.2

### Nuevo stack `spring_maria`

- Plantilla **`deploy/spring-3.9-java-17-maria-11/`**: Spring Boot (Maven 3.9 / Java 17) + MariaDB 11 en el mismo `docker-compose`.
- Overlay opcional **`docker-compose.maria-external-port.yml`** para publicar MariaDB en un puerto del host (`mysql_external_port` en `deploy.yml`).
- Variables de base (`mysql_user`, `mysql_db`, `mysql_pass`) definidas en `deploy.yml`; `deploy.sh` exporta JDBC y credenciales al compose (sin `.env` del proyecto).

### `deploy.sh` v1.2.0

- Checkout automático de la **`branch`** de cada servicio antes del build (`git fetch`, `reset --hard`, `clean -fd`).
- Soporte de stacks **`spring`**, **`spring_maria`** y **`angular`**.
- Compose multi-archivo para MariaDB con puerto externo.
- Diagnóstico Docker y validación **`nginx -t`** con salida completa en consola.

### Documentación

- **`deploy/deploy_doc.md`**: documentación actualizada con el stack `spring_maria`, campos MySQL y ejemplo completo de `deploy.yml`.
- **`deploy/deploy.yml`**: ejemplo comentado para `spring_maria`.
